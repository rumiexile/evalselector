# UI Kit — yokak.gov.tr institutional website

Recreation of the YÖKAK / THEQC public website home page (EN), built from the
live site's real structure and copy (top utility bar with phone + language
toggle + MIS link, logo header, primary nav, hero, news, document downloads,
footer with Bilkent/Ankara address).

Files:
- `index.html` — interactive home page (EN/TR header toggle is cosmetic).
- `SiteHeader.jsx` — utility bar + logo row + primary nav.
- `HomeSections.jsx` — hero band, news cards, documents list, stats.
- `SiteFooter.jsx` — contact block + link columns.

The kit composes design-system primitives (Button, Card, Badge, Alert,
SectionHeading, Logotype) from `_ds_bundle.js`. Content abbreviated (3 news
items standing in for the feed). No invented sections; layout follows the
site's institutional pattern. Imagery from the site was not copied — photo
areas are neutral placeholders.
